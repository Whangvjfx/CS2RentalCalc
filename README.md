# CS2租伴 (CS2 Rental Calc) - iOS 原生应用

专为 CS2 玩家与饰品出租者打造的**生活风、热情暖色调**饰品出租净利润记账与管理 iOS 原生应用。

## 🌟 核心特色与功能

1. **生活风与热情视觉设计**：
   - 采用暖落日橙、琥珀黄与珊瑚色调，告别冷冰冰的传统财务表格，让每次收租盘点都充满温暖与获得感。
   - 自适应深色与浅色模式，卡片轻盈温润。

2. **多饰品资产管理与现价随时波动**：
   - 支持录入多件 CS2 饰品（名称、分类、磨损度、购入价、现价、备注）。
   - **现价随时波动**：支持随时在卡片、详情页或调价面板中快捷调整饰品当前市场价格，即时重算资产浮盈与综合总净利润。

3. **严格区分渠道与手续费率 (0.2 vs 0.25)**：
   - **平台内购入**：扣除 **0.2 (20%)** 平台手续费，实际到手 80% 净租金。
   - **平台外购入**：扣除 **0.25 (25%)** 平台手续费，实际到手 75% 净租金。
   - 每一笔计划、每一个饰品都透明展示毛租金、扣除手续费与到手净租金。

4. **若干笔出租计划与综合净利润精确核算**：
   - 每个饰品可自由添加任意笔出租记录（出租天数、日租金、起租日期、状态、租客备注）。
   - **综合总净利润** = $\sum \text{各计划实际到手净租金} + \sum (\text{当前现价} - \text{购入成本})$。
   - 实时计算投资回报率 (ROI)、回本比例与距离完全收回本金的测算天数。

5. **全流程自动化云端构建**：
   - 基于 GitHub Actions (macOS 14 + 最新 Xcode + XcodeGen) 自动化打包原生 ARM64 `.ipa` 安装包。
